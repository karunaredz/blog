Multivariate Optimum Stratification and Sample Allocation
install.packages("multistrata")  ·  library(multistrata)

stratifyR finds optimal boundaries for surveys stratified on a single variable. In practice, many surveys stratify on two or more variables at the same time and need to estimate several study variables well. multistrata extends stratifyR to that general case.

It jointly determines boundaries and sample allocation across multiple stratification variables and multiple study variables, minimising a weighted composite variance objective. The algorithm alternates between a boundary update and an exact generalised Neyman allocation, embedded in a multi-start scheme to avoid poor local solutions.

NoteConnection to stratifyR

multistrata is the multivariate extension of the Reddy and Khan (2018) framework. Every single-variable design that stratifyR handles is a special case of what multistrata solves. The function names are different but the ideas are the same.

Quick Start

library(multistrata)

# simulate a two-variable population
set.seed(42)
pop <- sim_population(N = 5000, p = 2, q = 2, scenario = "independent")

# joint stratification on X1 and X2, estimating Y1 and Y2
res <- stratify_multi(
  data       = pop[, c("X1", "X2")],
  study_vars = pop[, c("Y1", "Y2")],
  H_vec      = c(3, 3),          # 3 strata per variable = 9 total strata
  n_total    = 500,
  omega      = c(0.5, 0.5),      # equal weight on both study variables
  n_starts   = 50
)
print(res)
summary(res)

H_vec gives the number of strata for each stratification variable. With H_vec = c(3, 3) you get a 3x3 grid of 9 strata in the joint space.

Core Function: stratify_multi()

The main function takes your population frame, your study variables, and a strata grid. It returns optimal boundaries, stratum sample sizes, and diagnostics.

Key arguments

stratify_multi(
  data,                    # stratification variables (N x p data frame or matrix)
  study_vars,              # study (target) variables (N x q)
  H_vec,                   # strata per variable, e.g. c(3, 3) or c(4, 2, 3)
  n_total,                 # total sample size
  omega      = NULL,       # study-variable weights (default: equal)
  constraint = "n_total",  # "n_total" or "cost"
  cost_total = NULL,       # budget C* (when constraint = "cost")
  cost_fixed = 0,          # fixed overhead deducted from budget
  cost_per_unit = 1,       # per-unit cost (scalar or H-vector)
  cv_targets = NULL,       # max CV per study variable, e.g. c(0.03, 0.03)
  distributions = NULL,    # NULL (empirical) or "auto" or named list of families
  method     = "cobyla",   # boundary solver: "cobyla" or "slsqp"
  n_starts   = 50,         # number of random starts
  n_min      = 2,          # minimum sample per stratum
  verbose    = FALSE,      # print per-start progress
  trace      = FALSE       # store per-iteration objective sequence
)
TipReproducibility

The multi-start scheme draws its initial boundaries at random. Always set a seed before any design you intend to report.

set.seed(1)
res <- stratify_multi(data, study_vars, H_vec = c(4, 3), n_total = 600)

Two Weight Modes

The stratum weights Wh (the fraction of the population in each stratum) can be estimated in two ways.

Empirical mode (default)

Wh is the sample proportion of units falling in each stratum. Uses only the data, no distributional assumptions. Set distributions = NULL.

Parametric mode

Wh is computed from marginal CDF differences under a fitted distribution. Set distributions = "auto" for AIC-based family selection, or supply families directly.

Auto mode picks the best-fitting marginal family per stratification variable:

res <- stratify_multi(
  data, study_vars, H_vec = c(3, 3), n_total = 500,
  distributions = "auto"
)
# res$.meta$distributions shows the selected families

You can also supply families directly:

dists <- list(
  X1 = list(family = "lnorm", meanlog = 1.2, sdlog = 0.8),
  X2 = list(family = "gamma", shape = 2.5, rate = 0.4)
)
res <- stratify_multi(data, study_vars, H_vec = c(3, 3), n_total = 500,
                      distributions = dists)

Supported families: norm, lnorm, gamma, exp, weibull, beta, unif, chisq, t, cauchy, logis, pareto, triang. When FitVerse is installed, auto mode can also search its 52 families.

Two Solvers

COBYLA (default)

method = "cobyla"
Derivative-free constrained optimisation. Works in both empirical and parametric modes. Robust and fast for most problems.

SLSQP

method = "slsqp"
Gradient-based solver using the closed-form weight gradient (Section 4.2 of the paper). Parametric mode only. Faster convergence when a good distribution fit is available.

Checking the solution

After fitting, check the quality diagnostics:

res$objective        # optimal composite variance Phi*
res$optimality_gap   # gap above the lower bound (0 = at the bound)
res$kkt_residual     # first-order stationarity residual
res$kkt_ok           # TRUE if residual is below tol_kkt
res$converged        # did the solver converge within max_iter?
res$n_starts_run     # number of random starts completed

Reading the Results

res$boundaries       # list of p boundary vectors (one per stratification variable)
res$allocation       # stratum sample sizes (integer vector of length H_total)
res$stratum_stats    # per-stratum N_h, W_h, n_h, A_h, within-stratum variances

The print method shows a formatted summary:

Precision-Driven Design: find_n()

The usual question is “given n, what is the best design?”. Sometimes the question runs the other way: “what is the smallest n that keeps all CVs below a target?”. find_n() answers that.

fn <- find_n(
  data       = pop[, c("X1", "X2")],
  study_vars = pop[, c("Y1", "Y2")],
  cv_targets = c(0.03, 0.03),     # max 3% CV on Y1 and Y2
  H_vec      = c(3, 3),
  n_starts   = 20
)
print(fn)
# fn$n          -- smallest feasible total sample size
# fn$allocation -- stratum sizes at that n
# fn$cv_achieved -- actual CVs achieved

It works by integer bisection over the CV-constrained allocation sub-problem. Boundaries are fixed from a single optimisation run and reused, which keeps the computation fast.

Choosing the Strata Grid: choose_H()

More strata always reduce variance, but the gains level off. choose_H() traces the optimal composite variance across a family of candidate grids and flags the elbow.

ch <- choose_H(
  data       = pop[, c("X1", "X2")],
  study_vars = pop[, c("Y1", "Y2")],
  n_total    = 500,
  H_each     = 2:5,       # tries 2x2, 3x3, 4x4, 5x5
  n_starts   = 10,
  plot       = TRUE
)
ch$table            # Phi*, optimality gap, relative gain per grid
ch$recommended      # recommended H_vec (elbow)

The plot shows the Phi* curve with the recommended grid marked. Go beyond the recommended grid only if the additional precision is worth the operational cost of more strata.

Priority Trade-Off: omega_sweep()

When you have two study variables and do not know how to weight them, omega_sweep() shows how the optimal design changes as the priority shifts from one to the other.

sw <- omega_sweep(
  data       = pop[, c("X1", "X2")],
  study_vars = pop[, c("Y1", "Y2")],
  H_vec      = c(3, 3),
  n_total    = 500,
  n_grid     = 11,           # 0%, 10%, ..., 100% weight on Y1
  n_starts   = 10
)
plot(sw)

The plot traces Phi* and per-variable variance against the weight on Y1. The flat middle region, if there is one, shows where the design is robust to the exact choice of weights.

Cost-Constrained Design

When sampling units in different strata cost different amounts, supply a per-stratum cost vector and a total budget instead of a fixed n.

res_cost <- stratify_multi(
  data          = pop[, c("X1", "X2")],
  study_vars    = pop[, c("Y1", "Y2")],
  H_vec         = c(3, 3),
  constraint    = "cost",
  cost_total    = 50000,
  cost_fixed    = 2000,         # fixed overhead (travel, setup)
  cost_per_unit = c(rep(20, 5), rep(40, 4)),   # H_total = 9 strata
  n_starts      = 30
)

The cost-aware design adjusts both boundaries and allocation. Strata with high per-unit costs get fewer units and the boundaries may shift to rebalance.

CV-Constrained Allocation

Specify maximum acceptable coefficients of variation for each study variable instead of (or alongside) a total sample size.

res_cv <- stratify_multi(
  data       = pop[, c("X1", "X2")],
  study_vars = pop[, c("Y1", "Y2")],
  H_vec      = c(3, 3),
  n_total    = 800,
  cv_targets = c(0.05, 0.04),   # 5% CV on Y1, 4% on Y2
  n_starts   = 30
)
res_cv$cv_achieved    # CVs actually achieved by the optimal allocation

Design Without Data: stratify_multi_density()

You can plan a stratified sample before collecting data, using assumed marginal distributions from a past survey or pilot study.

dists <- list(
  X1 = list(family = "lnorm", meanlog = 1.8, sdlog = 0.7),
  X2 = list(family = "gamma", shape = 3.0,   rate  = 0.5)
)
res_dens <- stratify_multi_density(
  distributions = dists,
  H_vec         = c(3, 3),
  n_total       = 400,
  omega         = c(0.5, 0.5)
)

Stratum weights are computed from the marginal CDFs. Study-variable moments come from Gauss-Kronrod quadrature of the marginal densities. This matches the empirical mode in the large-sample limit.

Survey Integration

Two functions take the optimal design into production.

assign_strata()

Applies the boundaries from a fitted design to any set of units: an estimation frame, a fresh census extract, or hold-out data.

# fit on a pilot sample, score the full frame
strata_labels <- assign_strata(res, newdata = full_frame[, c("X1", "X2")])
table(strata_labels)

The function matches columns by name when available, so you do not need to worry about column order.

as_svydesign()

Exports a survey::svydesign object ready for estimation with the survey package or srvyr.

svy <- as_svydesign(res, frame = pop)
# standard survey estimation from here
library(survey)
svymean(~Y1 + Y2, design = svy)

# or just a labelled frame for srvyr
labelled_frame <- as_svydesign(res, frame = pop, frame_only = TRUE)
# columns .stratum, .N_h, .n_h, .weight are added automatically

Visualisation

plot_strata(res)

For one stratification variable: density with boundary walls. For two variables: a 3-D perspective plot of the joint density with boundary planes. The same function works for any number of variables.

plot(res, which = "allocation")

Bar chart of stratum sample sizes. Shows how the allocation spreads across strata.

plot(res, which = "weights")

Stratum weights Wh as a bar chart. Useful for checking how uniformly the population is distributed across strata.

sw <- omega_sweep(data, study_vars, H_vec = c(3, 3), n_total = 500)
plot(sw)

Traces the precision trade-off as the weight shifts between two study variables.

Benchmarking

benchmark_designs() compares the multistrata design against simpler alternatives: proportional allocation, equal allocation, and two classical boundary rules (Dalenius-Hodges and Gunning-Horgan).

bm <- benchmark_designs(res, pop)
print(bm)

Results show composite variance and per-variable CVs for each design at the same total sample size.

Simulated Populations

sim_population() generates test populations with known structures.

pop <- sim_population(N = 5000, p = 2, q = 2, scenario = "independent")

Available scenarios:

Scenario Description
"independent" Stratification and study variables uncorrelated
"correlated" Moderate positive correlation between X and Y variables
"weibull_pareto" Heavy-tailed establishment-survey archetype
"copula" Dependent stratification variables via a Gaussian copula with log-normal margins

Shiny App

install.packages(c("shiny", "bslib", "DT", "plotly"))   # once
run_app()

The app exposes the full workflow without writing code:

Data input: upload your own CSV, generate a simulated population, or use one of the three built-in datasets
Design: set H_vec, n_total or budget, solver, weight mode, and omega
find_n: enter CV targets, get the minimum n
choose_H: scan candidate grids and view the elbow
Omega explorer: slide the priority weight and watch the design change
Benchmark: compare against proportional, equal, and classical rules
Visualise: boundary diagram, allocation bar chart, cost surface
Export: download report (PDF/HTML) and a reproducible R script with the set.seed() call

The generated R script includes the exact set.seed() call for the run shown on screen, so the design can be reproduced from the console.

Who Is multistrata For?

🏛 National Statistical Offices

Business and agricultural surveys that stratify on size and sector simultaneously, with precision targets on multiple indicators.

📐 Survey Methodologists

A reproducible, open implementation with formal convergence guarantees, optimality gaps, and KKT diagnostics for peer review.

🔬 Applied Researchers

Health, agricultural, economic, and environmental studies where more than one stratification variable is available at the design stage.

📊 Planning-Stage Design

Use the density mode and find_n() to plan a complete survey before collecting data, from distributional assumptions alone.

🎓 Teachers and Students

The Shiny app and sim_population() make the concepts of joint stratification and the Neyman trade-off easy to explore.
